# Level Up Tile

Luxury tile & stone website for Greenville & Upstate SC.

**Elevate Every Surface** — premium design and installation for homeowners, designers, and builders.

## Stack

- React 19 + TypeScript
- TanStack Start / Router
- Tailwind CSS v4
- Vite 8

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run typecheck
```

Deploy target: Vercel (Nitro preset).
